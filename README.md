# Quick-Res-2-Pro
Camera resolution manager built directly into Blender’s output panel.

Install:
1) Blender: Edit > Preferences > Add-ons > Install...
2) Select the zip, "Quick Res 2 Pro"

Where to find the addon:
- Properties panel > Output (printer icon) > "Quick Res 2 Pro"

What it does:
- Switch render resolution presets instantly
- Make your own presets (add / duplicate / remove / reorder)
- Filter by category (Landscape / Portrait / Square / Ultrawide / Custom)
- Export / Import presets
- Capture current scene resolution into a preset
